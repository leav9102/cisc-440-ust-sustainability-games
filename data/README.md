# Course data (local only)

Download these files from **Canvas → CISC 440 → Project Data** and save them in this folder.

## Required files

| File | Purpose |
|------|---------|
| `ust_selected_game_nodes.csv` | Game graph nodes (~10–15 locations) |
| `ust_building_edges.csv` | Walkable paths between buildings |
| `ust_building_coordinates.csv` | Map positions |
| `ust_distance_matrix.csv` | Pairwise distances |
| `ust_energy_assets.csv` | Energy cost / visit penalties |
| `ust_campus_resources.csv` | Recycling & sustainability services |
| `ust_sustainability_factors.csv` | Scores, weights, outcomes |
| `ust-clear building names.csv` | Building name lookup |
| `ust_sustainability_data_pack.xlsx` | Combined workbook (optional) |
| `ust_campus_map_plot.py` | Reference map plot |
| `sustainability_words.txt` | Word list (optional game 2) |

## Optional

- `Sustainability Trivia Game 2026.docx` — trivia-based second game

## Note

These files are **gitignored** so the repo stays small and respects course distribution. Every teammate must download their own copy from Canvas after cloning.
